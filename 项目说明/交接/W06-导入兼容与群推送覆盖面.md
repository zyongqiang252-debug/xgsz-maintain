## 1. 目标 / 不在范围

**目标（W06）**：让历史台账 `.xls`（Excel 2003 BIFF）也能导入；把「哪列对应哪个系统字段」存成模板，同表头的台账下次自动套用。
**目标（W07）**：钉钉群机器人原来只推工单事件，补上「库存跌破安全线」与「请假提交/批准/驳回」。

**不在范围**：
- 不做多 Sheet 解析（仍只读第一个 sheet）
- 不做「按客户自动绑定模板」（现在是按表头签名匹配，与客户无关）
- 不动工单状态机、归档六项校验、鉴权中间件、品牌名

## 3. 约束（不许动）

- 14 态状态机、归档六项校验、鉴权中间件、品牌名「芯光智数」
- `apply_stock_change()` 是库存变更唯一入口，别绕开它直接改 `stock_quantity`
- 群推送一律 `send_markdown_async`（后台线程）+ `try/except`，推送失败不能影响业务接口

## 4. 验收标准

```powershell
cd backend
.\.venv\Scripts\python.exe -m alembic current          # 期望 g6b7c8d9e0f1 (head)
.\.venv\Scripts\python.exe ..\tools\smoke_test.py      # 期望 28 通过 / 0 失败
```

手工验收：
1. 「历史工单导入」选一个 `.xls` 文件 → 能出表头预览（原来报"不支持旧版 .xls"）
2. 调好映射点「保存当前映射为模板」→ 重新选同表头的文件 → 顶部出现「已套用模板：xxx」
3. 出库让某备件库存跌破 `safety_stock` → 群里收到一次「备件库存预警」；继续出库不再重复推
4. 提交一张请假单 → 群里收到「新的请假申请待审批」
